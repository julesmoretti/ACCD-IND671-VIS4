# End-of-term feedback

One file per term, named `<TERM>-feedback.md` (e.g. `25FA-feedback.md`).

Each file should capture:

- **What students said** — course evaluations, whiteboard sessions, Slack, verbal
- **What I observed** — pacing, where people got stuck, what landed
- **Decisions made** — what changes this drove, and what was deliberately left alone

The point is that next year's changes are traceable to evidence rather than memory.
