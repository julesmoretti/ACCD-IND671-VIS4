Step 1: What is React Native?

React Native is an open-source framework developed by Facebook that allows developers to build mobile applications using JavaScript and React. Unlike traditional mobile development, which requires separate codebases for iOS and Android, React Native enables developers to write a single codebase that works across both platforms. It combines the best parts of native development with React, allowing you to create rich and responsive user interfaces that feel native on any device.

React Native is used for building cross-platform mobile applications, meaning you can develop apps for both iOS and Android with the same codebase. This reduces development time and costs while maintaining the performance and look-and-feel of a native app. Companies like Facebook, Instagram, Airbnb, and many others have successfully used React Native to build their apps, making it a popular choice for modern mobile app development.

Step 2: React vs. React Native

React is a JavaScript library primarily used for building web applications. It focuses on creating reusable UI components, which makes web development more efficient and scalable. React, being a library, works within the browser to build single-page applications and manage the user interface effectively.

React Native, on the other hand, is a framework built on top of React, designed specifically for mobile development. It allows developers to create mobile apps using JavaScript and React, but the output is not web-based; instead, it compiles to native code. This means React Native applications have a native look and feel and can take full advantage of the mobile device's hardware capabilities. Unlike React, which uses HTML for web development, React Native uses native components for iOS and Android, such as View, Text, and Image, to build mobile UI.

In summary, React is used to build web applications, whereas React Native is used to build cross-platform mobile applications. React Native builds upon the core concepts of React but extends them to create native mobile apps that perform well on both iOS and Android devices.

Using Native React Native Modules

React Native allows developers to access native functionalities of mobile devices through the use of native modules. These modules are written in the native language of the platform—Objective-C or Swift for iOS, and Java or Kotlin for Android—and are then linked to the JavaScript code. This allows developers to access features like the camera, GPS, and device sensors that would otherwise require platform-specific code. You can use existing native modules, or even write your own if necessary.

Expo, the framework we use in this curriculum, provides a standard library of native modules that work seamlessly with Expo Go, simplifying access to device features. For example, to use the device's camera, you can install the expo-camera package, which is compatible with Expo Go and provides a simple API for camera functionality:

npx expo install expo-camera

After installing, configure camera permissions in your app.json file:

{
  "expo": {
    "plugins": [
      [
        "expo-camera",
        {
          "cameraPermission": "Allow $(PRODUCT_NAME) to access your camera",
          "microphonePermission": "Allow $(PRODUCT_NAME) to access your microphone",
          "recordAudioAndroid": true
        }
      ]
    ]
  }
}

Once installed and configured, you can import and use the expo-camera module in your JavaScript code. For example, in a file like screen3.tsx, you can create a camera screen with a button to flip between front and back cameras:

import { CameraView, CameraType, useCameraPermissions } from 'expo-camera';
import { useState } from 'react';
import { Button, StyleSheet, Text, TouchableOpacity, View } from 'react-native';

export default function Screen3() {
  const [facing, setFacing] = useState<CameraType>('back');
  const [permission, requestPermission] = useCameraPermissions();

  if (!permission) {
    return <View />;
  }

  if (!permission.granted) {
    return (
      <View style={styles.container}>
        <Text style={styles.message}>We need your permission to show the camera</Text>
        <Button onPress={requestPermission} title="grant permission" />
      </View>
    );
  }

  function toggleCameraFacing() {
    setFacing(current => (current === 'back' ? 'front' : 'back'));
  }

  return (
    <View style={styles.container}>
      <CameraView style={styles.camera} facing={facing} />
      <View style={styles.buttonContainer}>
        <TouchableOpacity style={styles.button} onPress={toggleCameraFacing}>
          <Text style={styles.text}>Flip Camera</Text>
        </TouchableOpacity>
      </View>
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    justifyContent: 'center',
  },
  message: {
    textAlign: 'center',
    paddingBottom: 10,
  },
  camera: {
    flex: 1,
  },
  buttonContainer: {
    position: 'absolute',
    bottom: 64,
    flexDirection: 'row',
    backgroundColor: 'transparent',
    width: '100%',
    paddingHorizontal: 64,
  },
  button: {
    flex: 1,
    alignItems: 'center',
  },
  text: {
    fontSize: 24,
    fontWeight: 'bold',
    color: 'white',
  },
});

The expo-camera module is a robust and Expo-friendly library for accessing the device’s camera. It supports features like taking photos, recording videos, and switching cameras, and works out of the box with Expo Go. For more details, refer to the official Expo Camera documentation: https://docs.expo.dev/versions/latest/sdk/camera/.

Step 3: Configuring Your System for React Native Development

To get started with React Native, you'll need to configure your computer to develop and run React Native applications. Here, we'll cover the setup process for both Mac and Windows PCs.

Step 3a: Setting Up React Native on a Mac

We recommend using Expo, a framework that simplifies the process of developing React Native apps. Expo provides developer tooling that makes app development easier, such as file-based routing and a standard library of native modules.

  1. Install Xcode using the app store.
  2. Install Expo CLI: Install Expo CLI globally by running:
npm install -g expo-cli
  1. Create a New Expo Project: Use the following command to create a new Expo project:
npx create-expo-app@latest
  1. Install iOS Simulator: Open Xcode, then go to Preferences > Components, and install the latest iOS version to use the simulator for testing your app.
  2. Install Watchman: Watchman is a tool for monitoring changes in the filesystem. Installing it will improve performance:
brew install watchman

Step 3b: Setting Up React Native on a Windows PC

We recommend using Expo, a framework that simplifies the process of developing React Native apps. Expo provides developer tooling that makes app development easier, such as file-based routing and a standard library of native modules.

  1. Install Expo CLI: Install Expo CLI globally by running:
npm install -g expo-cli
  1. Create a New Expo Project: Use the following command to create a new Expo project:
npx create-expo-app@latest
  1. Install Android Studio (Optional): If you also want to build Android apps, download and install Android Studio from developer.android.com. Make sure to install the Android SDK and set up an Android Virtual Device (AVD) for testing.

Step 4: Creating Your First React Native App

  1. Navigate to Your Project Directory: Open your terminal or command prompt and navigate to the directory of your newly created Expo project:
cd MyExpoApp
  1. Reset the Project: Run the following command to reset the project and set up a basic app structure with a single screen:
npm run reset-project
  1. Add Bottom Tab Navigation: To create an app with multiple screens, use Expo Router’s file-based routing to add a bottom tab navigation bar with three screens: Home, Screen 2, and Screen 3 (Camera). Follow these steps:
    1. Update app/_layout.tsx: Replace the default Stack navigator with a Tabs navigator to create a bottom tab bar. Create or modify app/_layout.tsx as follows:
import { Tabs } from "expo-router";
import { Text } from "react-native";

export default function RootLayout() {
  return (
    <Tabs
      screenOptions={{
        headerShown: false,
        tabBarStyle: {
          backgroundColor: "#fff",
          borderTopWidth: 1,
          borderTopColor: "#ccc",
        },
        tabBarActiveTintColor: "#007AFF",
        tabBarInactiveTintColor: "#888",
      }}
    >
      <Tabs.Screen
        name="index"
        options={{
          title: "Home",
          tabBarIcon: ({ color, size }) => (
            <Text style={{ color, fontSize: size }}>🏠</Text>
          ),
        }}
      />
      <Tabs.Screen
        name="screen2"
        options={{
          title: "Screen 2",
          tabBarIcon: ({ color, size }) => (
            <Text style={{ color, fontSize: size }}>📖</Text>
          ),
        }}
      />
      <Tabs.Screen
        name="screen3"
        options={{
          title: "Screen 3",
          tabBarIcon: ({ color, size }) => (
            <Text style={{ color, fontSize: size }}>⚙️</Text>
          ),
        }}
      />
    </Tabs>
  );
}
    1. Create app/screen2.tsx: Add a second screen for the tab navigation:
import { Text, View } from "react-native";

export default function Screen2() {
  return (
    <View
      style={{
        flex: 1,
        justifyContent: "center",
        alignItems: "center",
      }}
    >
      <Text>Welcome to Screen 2!</Text>
    </View>
  );
}
    1. Create app/screen3.tsx with Camera: Convert Screen 3 to use the camera with expo-camera, as shown in the native modules section above.
    2. Install expo-camera: Run the following command to install the camera module:
npx expo install expo-camera
    1. Start the Development Server: Run the following command to start the development server:
npx expo start
  1. Open the App: Open the app in an iOS simulator, Android emulator, or on your physical device using Expo Go. To open in the iOS simulator, press i. To open in the Android emulator, press a. On a physical device, scan the QR code with the Expo Go app.
  2. Test the App: Navigate to the tabs (Home, Screen 2, Screen 3). On Screen 3, grant camera permissions when prompted to display the camera feed and test the "Flip Camera" button.
  3. Edit Your App: Open the project in your code editor (e.g., VS Code) and edit app/index.tsx, app/screen2.tsx, or app/screen3.tsx to customize your app further.

Step 5: Deploying Your React Native App

Step 5a: Deploying to iOS TestFlight

To deploy your React Native app to iOS TestFlight, follow these steps:

  1. Open Xcode Project: Open the iOS folder of your React Native project in Xcode by navigating to ios/MyReactNativeApp.xcodeproj.
  2. Update App Information: Update the app's information, such as version and build number, in the General tab in Xcode.
  3. Archive the App: Choose Product > Archive from the top menu in Xcode. This will create a build of your app that you can upload to App Store Connect.
  4. Upload to App Store Connect: After the archive is created, select Distribute App, and follow the prompts to upload your app to App Store Connect.
  5. TestFlight Testing: Once the app is uploaded, use TestFlight to invite testers and distribute your app.

Step 5b: Deploying to Android Play Store (Using Mac or Windows)

To deploy your React Native app to the Google Play Store, follow these steps:

  1. Generate a Signed APK: Navigate to the android directory of your project, and run the following command to generate a signed APK:
cd android
./gradlew assembleRelease
  1. Sign the APK: You need to sign your APK using the Java Keytool. If you haven't already, create a keystore by running the following command:
keytool -genkey -v -keystore my-release-key.keystore -alias my-key-alias -keyalg RSA -keysize 2048 -validity 10000
  1. Configure Gradle for Signing: Edit android/app/build.gradle to include the signing configuration for your release build.
  2. Upload to Google Play Console: After generating the signed APK, go to the Google Play Console, create a new app, and upload the signed APK to the Play Store.

Step 5c: Final Steps for Deployment

Once your app is available on TestFlight or the Google Play Store, you can invite users to test it and gather feedback. Make sure to monitor the feedback and fix any bugs or usability issues. This step is crucial to ensure a smooth experience for your end users.
