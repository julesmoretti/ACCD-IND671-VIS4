This section of the class focuses on helping students understand the fundamentals of React by walking through the steps required to set up and work with a simple React project, including the introduction to JSX, props, components, and state management.

0. Setup: Installing and Creating a React App

The first step is to install the necessary tools and set up a new React app.

  1. Install Create React App:

    The tool create-react-app scaffolds a React project, handling all the setup so you can focus on writing React code.

    npm install -g create-react-app
  2. Create a New React App:

    Once installed, use create-react-app to generate a new project. For this class, we’ll create a project named number-adder.

    create-react-app number-adder
  3. Start the Development Server:

    Navigate to the project folder and start the development server:

    cd number-adder
    npm start

    This launches the app in the browser at http://localhost:3000 and sets up a live-reloading environment, so changes you make in your code will immediately reflect in the browser.

1. Anatomy of a React App

Once the React app is generated, it's crucial to understand the basic structure of the project and what each file does. This will help students navigate the project and understand where they should write their code.

  • /public Folder:
    • index.html: This is the base HTML file that serves as the entry point for the entire application. React will inject the app components into this file dynamically.
    • Other files like the favicon and manifest for branding or functionality.
  • /src Folder:
    • index.js: The entry point for the React app. It renders the root component (usually App.js) into the DOM.
    • App.js: The main React component. Initially, this is a functional component that returns JSX.
    • App.css: Styles for App.js.
    • index.css: Global styles for the app.
  • package.json:

    Lists project dependencies and scripts, such as npm start and npm test.

2. JSX Format, Props, and className

React uses JSX (JavaScript XML) to define the structure of components. JSX is similar to HTML, but with some important differences. We'll cover how JSX works and how to pass data between components using props.

  • JSX Basics:

    JSX allows HTML-like syntax directly in JavaScript.

    const title = "Number Adder";
const subtitle = "React Version";

return (
  <div>
    <h1>{title}</h1>
    <h3>{subtitle}</h3>
  </div>
);
  • Props:

    Props are how you pass data from a parent component to a child component.

    function Navbar(props) {
  return <h1>{props.title}</h1>;
}

function App() {
  return <Navbar title="Number Adder" />;
}
  • className vs. class:

    Since JSX is embedded in JavaScript, class in HTML is replaced by className.

    <div className="container">Hello</div>

3. Creating a React Component and Injecting it into App.js

React applications are made up of components. Components are JavaScript functions (or classes) that return JSX and represent pieces of the UI. Let’s break down how to create a simple React component and integrate it into the App.js file.

  • Creating a Component: 
    // in a new file called Navbar.js
function Navbar() {
  return (
    <div id="navbar">
      <h1>Number Adder</h1>
      <h4>Item 1</h4>
      <h4>Item 2</h4>
    </div>
  );
}

export default Navbar;
  • Injecting the Component into App.js: 
    import Navbar from './Navbar';

function App() {
  return (
    <div>
      <Navbar />
      <p>This is the main content of the app.</p>
    </div>
  );
}

export default App;

4. State Management: useState, Props vs. State, Localized vs Distributed

State is one of the core concepts of React, allowing components to "remember" things between renders. State is different from props in that it’s local to a component and can change over time, while props are passed down from a parent component and are read-only.

  • useState Hook: 
    import React, { useState } from 'react';

function Counter() {
  const [count, setCount] = useState(0);

  return (
    <div>
      <p>Total: {count}</p>
      <button onClick={() => setCount(count + 1)}>Add 1</button>
      <button onClick={() => setCount(count - 1)}>Remove 1</button>
      <button onClick={() => setCount(0)}>Reset</button>
    </div>
  );
}

export default Counter;
  • State vs. Props:

    Props are passed into components from parent components and are immutable. State is local to a component and can be updated.

  • Localized vs. Distributed State:

    Localized state is managed inside a single component. Distributed state refers to shared state across multiple components, often managed with context or external libraries like Redux.
