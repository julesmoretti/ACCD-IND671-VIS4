Part 2: React

In this section, we will convert last week’s homework into a React app using Vite. We will start by creating a new React project, then gradually convert the HTML sections into React components. Finally, we will refactor the logic so that the button interactions within the main content update the sidebar with the result and operation history.

One idea carries over from Week 3 and changes shape: there, every button changed the data and then called updateResults() to redraw the page. In React you only change the data (the state); React redraws the page for you. There is no updateResults() to write.

Step 1: Setting up the React App

We’ll start by setting up the project in the same way as the previous section. Run these commands from inside your vis4/week 4 folder so the project lands in your repo.

  1. Create the React App:

    Use Vite to generate a new React project. There is nothing to install globally first:

    npm create vite@latest number-adder -- --template react

    Choose the plain react template, not react-ts.

  2. Install the Dependencies: 
    cd number-adder
    npm install
  3. Open the Project and Start the Development Server: 
    subl .
    npm run dev

    This will open the app in your browser at http://localhost:5173.

Step 2: Convert Header to a React Component

We’ll start by refactoring the header section from last week’s homework into its own reusable React component.

1. First, create a new file in the src folder called Header.jsx. This file will contain the header component.

2. In Header.jsx, define a function component that represents the header:

import React from 'react';

function Header() {
  return (
    <div id="navbar">
      <h1>Number Adder</h1>
      <h4>Item 1</h4>
      <h4>Item 2</h4>
      <h4>Item 3</h4>
    </div>
  );
}

export default Header;

3. Next, import this Header component into the App.jsx file and render it as part of the main app:

import React from 'react';
import Header from './Header'; // Import the Header component

function App() {
  return (
    <div>
      <Header />
      {/* Other components will go here */}
    </div>
  );
}

export default App;

This creates a reusable Header component that you can easily include in other parts of the app or adjust independently.

Step 3: Convert Sidebar and Main Content to React Components

Now we’ll convert the sidebar and main content into separate React components. These components will manage the layout of the buttons, results, and history.

1. Create a new file called Sidebar.jsx:

import React from 'react';

function Sidebar({ total, history }) {
  return (
    <div className="sidebar">
      <h3>Result</h3>
      <p>Total: {total}</p>
      <h3>History</h3>
      <ul>
        {history.map((entry, index) => (
          <li key={index}>{entry}</li>
        ))}
      </ul>
    </div>
  );
}

export default Sidebar;

Explanation of the .map() method:

The .map() method is used to iterate over an array and generate a new array based on the transformation provided in the callback function. In this example, we use .map() to iterate over the history array, and for each entry, we return a <li> element that displays the history entry in the sidebar.

In simple terms, .map() takes each element of the array and creates a new list item (<li>) to display on the page. The result is an array of list items that React can render dynamically.

Why use key={index}?

When rendering lists in React, you need to assign a unique key to each list item. This helps React efficiently track and update items when the list changes. In this case, we're using the array index as the key, which is sufficient here because the order of the items doesn't change. However, in more complex apps, using a unique identifier (such as an ID) is preferred to avoid potential issues when items are added, removed, or reordered.

2. Create a new file called MainContent.jsx:

import React from 'react';

function MainContent({ onAddOne, onAddTwo, onReset, onRemoveOne, onRemoveTwo }) {
  return (
    <div className="content">
      <h3>Control Center</h3>
      <div className="buttonControls">
        <button onClick={onRemoveTwo}>-2</button>
        <button onClick={onRemoveOne}>-1</button>
        <button onClick={onReset}>Reset</button>
        <button onClick={onAddOne}>+1</button>
        <button onClick={onAddTwo}>+2</button>
      </div>
    </div>
  );
}

export default MainContent;

3. Now, import the Sidebar and MainContent components into App.jsx and render them:

import React, { useState } from 'react';
import Header from './Header';
import Sidebar from './Sidebar';
import MainContent from './MainContent';

function App() {
  const [total, setTotal] = useState(0);
  const [history, setHistory] = useState([]);

  function handleAddOne() {
    setTotal(total + 1);
    setHistory([...history, '+1']);
  }

  function handleAddTwo() {
    setTotal(total + 2);
    setHistory([...history, '+2']);
  }

  function handleRemoveOne() {
    setTotal(total - 1);
    setHistory([...history, '-1']);
  }

  function handleRemoveTwo() {
    setTotal(total - 2);
    setHistory([...history, '-2']);
  }

  function handleReset() {
    setTotal(0);
    setHistory([...history, 'Reset']);
  }

  return (
    <div>
      <Header />
      <div id="main-content">
        <Sidebar total={total} history={history} />
        <MainContent
          onAddOne={handleAddOne}
          onAddTwo={handleAddTwo}
          onRemoveOne={handleRemoveOne}
          onRemoveTwo={handleRemoveTwo}
          onReset={handleReset}
        />
      </div>
    </div>
  );
}

export default App;

Explanation of [...history] (Spread Operator):

The [...history] syntax is known as the spread operator. It’s used here to create a copy of the existing history array and add a new entry to it (like +1 or -2). Without using the spread operator, we would modify the original array directly, which can lead to bugs and unwanted side effects. The spread operator allows us to create a new array while keeping the previous elements intact, ensuring that React properly detects the state update and re-renders the component.

Step 4: Bring Your Week 3 Styles Across

For each button click (e.g., onAddOne), the total is updated using setTotal, and the history is updated using setHistory. The page now works, but it will not look like your Week 3 page yet: Vite's starter CSS centres everything in a fixed-width column, centres the text, and switches to dark mode.

  1. Delete everything in src/App.css and src/index.css.
  2. Paste the contents of your Week 3 styles.css into src/index.css.
  3. Make the ids and classes in your components match the ones your CSS uses (for example id="navbar" or className="sidebar"). Remember: class becomes className in JSX.
