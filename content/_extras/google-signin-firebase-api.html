Step 1: Create a New React App

# Create a new React app
npx create-react-app sign-in-app
cd sign-in-app

Step 2: Set Up Firebase Project & Enable Google Sign-In

  1. Go to the Firebase Console.
  2. Click on Create a project, follow the steps to create a project, and disable Google Analytics.
  3. In the Firebase dashboard, register a Web App by clicking on the </> icon.
    • Copy the Firebase SDK configuration; you'll need it later.
  4. Enable Google Sign-In in Authentication > Sign-in Method. By clicking on Get started and selecting Google. Toggle enable on and select your e-mail, then click save.

Step 3: Install Firebase SDK

npm install firebase

Create a firebase.js file in the src/ directory:

import { initializeApp } from 'firebase/app';
import { getAuth } from 'firebase/auth';

const firebaseConfig = {
  apiKey: process.env.REACT_APP_FIREBASE_API_KEY,
  authDomain: process.env.REACT_APP_FIREBASE_AUTH_DOMAIN,
  projectId: process.env.REACT_APP_FIREBASE_PROJECT_ID,
  storageBucket: process.env.REACT_APP_FIREBASE_STORAGE_BUCKET,
  messagingSenderId: process.env.REACT_APP_FIREBASE_MESSAGING_SENDER_ID,
  appId: process.env.REACT_APP_FIREBASE_APP_ID
};

const app = initializeApp(firebaseConfig);
export const auth = getAuth(app);

Ensure you add environment variables in .env (place in the root directory):

REACT_APP_FIREBASE_API_KEY=your_api_key
REACT_APP_FIREBASE_AUTH_DOMAIN=your_auth_domain
REACT_APP_FIREBASE_PROJECT_ID=your_project_id
REACT_APP_FIREBASE_STORAGE_BUCKET=your_storage_bucket
REACT_APP_FIREBASE_MESSAGING_SENDER_ID=your_messaging_sender_id
REACT_APP_FIREBASE_APP_ID=your_app_id

Step 4: Implement Google Sign-In and Display User Info

In App.js, add Google Sign-In logic:

import React, { useState, useEffect } from 'react';
import {
  GoogleAuthProvider,
  signInWithPopup,
  onAuthStateChanged,
  signOut,
} from 'firebase/auth';
import { auth } from './firebase';
import './App.css';

function App() {
  const [googleUser, setGoogleUser] = useState(null);

  useEffect(() => {
    const unsubscribe = onAuthStateChanged(auth, (currentUser) => {
      setGoogleUser(currentUser);
    });
    return () => unsubscribe();
  }, []);

  const signInWithGoogle = () => {
    const provider = new GoogleAuthProvider();
    signInWithPopup(auth, provider)
      .then((result) => setGoogleUser(result.user))
      .catch((error) => alert(error.message));
  };

  const handleSignOut = () => signOut(auth);

  return (
    <div className="App">
      <header className="App-header">
        {googleUser ? (
          <div>
            <img src={googleUser.photoURL.slice(0, -6)} alt="profile" />
            <p>Welcome, {googleUser.displayName}</p>
            <button onClick={handleSignOut}>Sign Out</button>
          </div>
        ) : (
          <button onClick={signInWithGoogle}>Sign In with Google</button>
        )}
      </header>
    </div>
  );
}

export default App;

Step 6: API Integration - Instagram Personal Feed

Now, let's use the Instagram Basic Display API to fetch and display the first 6 images from a user's Instagram account. Follow the steps below:

  1. Go to the Instagram Developer Site, click on My Apps and then Create App.
  2. Under Use cases select Other.
  3. Under Type select Consumer.
  4. Give your app a name google-sign-in-app.
  5. In your app, enable Instagram Basic Display by clicking on Set Up, then Create New App.
  6. Under User Token Generator section, click on User Token Generator and then Add People, then add yourself.
  7. Visit Manage Access, click the Tester Invites tab, and Accept the invite.
  8. Go back to the Instagram Developer Dashboard and click on Generate Token.
  9. Copy the generated access token and add it to your .env file as follows:
REACT_APP_INSTAGRAM_ACCESS_TOKEN=your_access_token
  1. Install Axios to fetch Instagram data:
npm install axios

In instagramFeed.js, fetch Instagram data by replacing the placeholder with your access token:

import React, { useState, useEffect } from 'react';
import axios from 'axios';
import './instagramFeed.css';

function InstagramFeed() {
  const [photos, setPhotos] = useState([]);

  useEffect(() => {
    const fetchInstagramPhotos = async () => {
      try {
        const response = await axios.get(
          `https://graph.instagram.com/me/media?fields=id,media_type,media_url&limit=6&access_token=${process.env.REACT_APP_INSTAGRAM_ACCESS_TOKEN}`
        );
        setPhotos(response.data.data);
      } catch (error) {
        console.error('Error fetching Instagram data', error);
      }
    };
    fetchInstagramPhotos();
  }, []);

  return (
    <div className="instaFeed">
      {photos.map((photo) => (
        <img
          className="instagrams"
          key={photo.id}
          src={photo.media_url}
          alt="Instagram media"
        />
      ))}
    </div>
  );
}

export default InstagramFeed;

Create instagramFeed.css, add the following styles:

.instaFeed {
  padding-top: 40px;
  display: flex;
}

.instagrams {
  border-radius: 0;
  width: calc(100vw / 6);
  object-fit: cover;
}

Go back to app.js, add include the InstagramFeed component.

// insert this at the top of your file
import InstagramFeed from './instagramFeed';

// add the InstagramFeed bellow the Sign Out button
<button onClick={handleSignOut}>Sign Out</button>
<InstagramFeed />

This integration will load the first 6 photos from the user’s Instagram account and display them in the app after they sign in with Google.

NOTE: If you are getting any error with regards to Token calls or firebase issues, make sure to restart your terminal.
