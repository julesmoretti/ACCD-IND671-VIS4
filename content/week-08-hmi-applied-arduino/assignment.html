Part 1: HMI Document (version 1)

As discussed during class, this week's assignment is to create an HMI document for your class final presentation.

IMPORTANT NOTE: This assignment is worth 50 points, so please make sure that you carefully go through all the points below and that this documentation is very thorough and clear. This will act as a solid foundation for your presentation.

The HMI document should have the following requirements.

  1. A Product Information tab with the following information within it:
    1. Product Name
    2. Description of the product - Intended use, location of usage, and basic functionalities.
    3. Any link to relevant presentation or online portfolio piece of it.
    4. A diagram of the product that includes leader lines to some of the important HMI features
  2. A second tab called UX, with the following:
    1. Interactions (Ex: Power ON)
    2. User Needs (Ex: As a user, when I [perform an action], I expect [desired outcome], so that [benefit or purpose])
    3. Interaction Types (physical button press, touchscreen, voice command)
    4. Feedback (e.g., visual, auditory, haptic)
    5. Priority (How important this feature is for the product functionality)
    6. Prototype Complexity (this is a new column that is similar to the Priority column but that is specifically around how simple or complex this would be to prototype considering what we have covered during class or not)
    7. Software integrations
    8. Notes
    9. And Please separate your interactions by categories for example (Power, Connectivity, Audio Controls, Graphics etc...)
