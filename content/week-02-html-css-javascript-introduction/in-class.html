Exercise 1: Building a Basic HTML and CSS Page

Step 1: Create the Basic Structure with Two Divs (Rows for Layout)

  1. Objective: Build a basic webpage structure using <div> tags. This will consist of two sections: a top navigation bar and a main content section below it.
  2. Instructions:
    • Create a new HTML file (index.html).
    • Add two <div> elements:
      • Top div: For the navigation bar. It should take up 100% width and 150px height.
      • Bottom div: This takes up the remaining vertical space on the page.
    • Example HTML: 
      <body>
    <div id="navbar">
        <h1>Navigation Bar</h1>
    </div>
    <div id="main-content">
        <h2>Main Content Area</h2>
    </div>
</body>
  3. Add Basic CSS for Layout:
    • Style the #navbar and #main-content divs using internal CSS.
    • Set distinct background colors to visually separate them, and ensure the bottom div takes the remaining vertical space using height: calc(100vh - 150px);
    • Example CSS: 
      #navbar {
    background-color: #333;
    color: white;
    height: 150px;
    width: 100%;
    text-align: center;
}

#main-content {
    background-color: #f4f4f4;
    height: calc(100vh - 150px);
    padding: 20px;
}

Exercise 2: Breaking Apart HTML and CSS

Step 1: Separate Internal CSS into an External CSS File

  1. Objective: Refactor the HTML by moving internal styles into an external stylesheet for better organization and reusability.
  2. Instructions:
    • Create an external CSS file named styles.css.
    • Move the CSS rules from the <style> block in the HTML document into this new file.
    • Link the styles.css file in the <head> section using the <link> tag.
  3. Example HTML (after moving styles to an external file): 
    <head>
    <link rel="stylesheet" href="styles.css">
</head>
  4. Example CSS (in styles.css): 
    #navbar {
    background-color: #333;
    color: white;
    height: 150px;
    width: 100%;
    text-align: center;
}

#main-content {
    background-color: #f4f4f4;
    height: calc(100vh - 150px);
    padding: 20px;
}

Exercise 3: Introducing Flexbox Layout

Step 1: Add Nested Divs and Use Flexbox for Layout

  1. Objective: Add two nested <div> elements inside the #main-content section to create a sidebar and a content area. Use Flexbox to manage the layout.
  2. Instructions:
    • Inside #main-content, create two divs with classes .sidebar and .content.
    • Use Flexbox to arrange them in a horizontal row.
  3. Updated HTML: 
    <div id="main-content">
    <div class="sidebar">
        <h3>Sidebar Navigation</h3>
    </div>
    <div class="content">
        <h3>Main Content</h3>
    </div>
</div>
  4. Add Flexbox CSS:
    • Refactor the CSS to apply a Flexbox layout to #main-content.
    • The sidebar should have a fixed width of 400px, and the content area should take the remaining space.
  5. Example CSS (in styles.css): 
    #main-content {
    display: flex;
    height: calc(100vh - 150px);
}

.sidebar {
    background-color: #ddd;
    width: 400px;
    height: 100%;
}

.content {
    background-color: #fff;
    flex: 1;
    padding: 20px;
}
  6. Responsive Design:
    • To make the layout more responsive, add a media query that reduces the sidebar width on smaller screens.
  7. Example Media Query: 
    @media (max-width: 800px) {
    .sidebar {
        width: 200px;
    }
}

Exercise 4: JavaScript Event Listeners and DOM Manipulation

Step 1: Add Interactivity with JavaScript Event Listeners

  1. Objective: Add a button that changes the color of the heading inside the #navbar when clicked.
  2. Instructions:
    • Add a button inside the #navbar: 
      <button id="changeColorBtn">Change Header Color</button>
    • Write JavaScript that listens for the button click and changes the header's text color.
  3. Example JavaScript: 
    <script>
document
    .getElementById("changeColorBtn")
    .addEventListener("click", function() {

        document
            .querySelector("#navbar h1")
            .style
            .color = "green";
});
</script>

Step 2: Inject Content Dynamically Using JavaScript

  1. Objective: Use JavaScript to inject content into the .content div when the button is clicked.
  2. Instructions:
    • Inside the same event listener, add a line of code that injects content into the .content div.
  3. Example JavaScript: 
    <script>
document
    .getElementById("changeColorBtn")
    .addEventListener("click", function() {
        document
            .querySelector("#navbar h1")
            .style
            .color = "green";

        document
            .querySelector(".content")
            .innerHTML = "<p>New content added!</p>";
});
</script>
