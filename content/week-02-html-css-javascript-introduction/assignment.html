Part 2: Start Your Project Interface

The Number Adder is practice. This part is the real thing, and it starts now because you will still be working on it in Week 14.

Your device needs a control interface — the screen a user touches to make your hero experience happen. By the end of term it will be a React application talking to your Arduino over WebSocket. This week it is static HTML and CSS.

What to build

A first pass at the screen for your hero experience. Nothing needs to work yet — no JavaScript, no interactivity. You are laying out the elements a user would need:

  • What does the user set or choose?
  • What does the device tell them back — status, progress, confirmation?
  • What can they do mid-action — stop, pause, adjust?

For the rubber band winder example, that might be a target input, a start button, a live turn count, and a stop button. Four elements. That is enough.

Keep it small

One or two screens. Not an app — a control interface for one interaction. If you find yourself designing a settings page or an account flow, you have drifted off the hero experience.

You will build on this every week: JavaScript in Week 3, React in Week 4, and a user test before the midterm. Starting small is what makes that possible.
