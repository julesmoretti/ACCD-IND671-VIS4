Number Adder

Create an HTML page with CSS styling in a separate page, and include JavaScript to make some live calculations. The page should display a result, and the capability to add to the result +1, +2, or -1, -2, or the reset the value back to 0. Once all complete push your code to your repo and use that to share that back to me.

Requirements:

  • The header title should have your first name followed by Number Adder
  • The page should be divided between 3 DIV's (a Header DIV, a sidebar DIV, and a main-content DIV)
  • The header DIV should have a series of flex informations (h1, h4, h4 ,h4)
  • The sidebar should have an h3 RESULT title followed by a p (paragraph) that uses id="resultId" to keep track of it.
  • The main-content section should comprise an H3 header that says: "Control Center", followed by a flex div, that has within it 5 button with unique ID's for each of them
  • Your JavaScript section should start off with a variable called total and be assigned the value 0 like so: var total = 0;
  • Your JavaScript should have five document.getElementById("someUniqueIdPerButtons").addEventlisten...
  • Within each of those five unique event listeners, the function should start with: total = total -1 (the last piece in this case -1 depends on the button operation, it could be -2, +1, +2 or simply total = 0) 
  • And finally within each of the event listener your file should also include a document.querySelector("#resultId").innerHTML = total;
  • Once the above complete when clicking on those buttons you should see the result value change according to your button.
  • Styling, take some time to change the styling of your layout by figuring out how to center text, capitalize text, change the font weight, background colors of DIV's, margin's versus padding's, feel free to get creative there.
  • Finally commit your work to your repo and push it to GitHub
