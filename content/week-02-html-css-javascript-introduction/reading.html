Part 1: Theoretical Overview (1st half of the class)

1. Introduction to HTML

  • What is HTML?
    • HTML (HyperText Markup Language) is the standard language for creating web pages. It structures content on a webpage using "tags."
    • Key concept: HTML is the skeleton of a webpage. It defines elements such as headings, paragraphs, lists, links, and images.
  • HTML Syntax:
    • Tags are written within angle brackets: <tagname>Content</tagname>.
    • Tags are opened with <tagname> and closed with a forward slash: </tagname>.
    • Common tags:
      • <!DOCTYPE html>: Declares the document type.
      • <html>: Wraps the entire content of the webpage.
      • <head>: Contains metadata (e.g. title, linked resources like CSS).
      • <body>: Contains the visible content (e.g. headings, paragraphs, links).
  • Example: 
    <html>
    <head>
        <title>My Webpage</title>
    </head>
    <body>
        <h1>Welcome to My Webpage</h1>
        <p>This is a simple HTML page.</p>
    </body>
</html>

2. Introduction to CSS

  • What is CSS?
    • CSS (Cascading Style Sheets) is a language used to style and lay out web pages, making them visually appealing.
    • Key concept: CSS controls the look and feel of a webpage by applying rules to HTML elements.
  • CSS Syntax:
    • Selectors target HTML elements.
    • Declaration blocks contain properties and their values.
    • Example: 
      h1 {
    color: blue;
    font-size: 24px;
}
  • Inline vs. Internal vs. External CSS:
    • Inline: Style rules directly within an HTML tag.
    • Internal: Style rules placed inside a <style> tag within the document's <head>.
    • External: Style rules stored in an external .css file, linked via the <link> tag.
  • Example: 
    <html>
    <head>
        <title>CSS Example: Inline, Internal, and External</title>

        <!-- External CSS: Linking to an external CSS file -->
        <link rel="stylesheet" href="styles.css">

        <!-- Internal CSS: Styling within the HTML file -->
        <style>
            body {
                font-family: Arial, sans-serif;
                background-color: #f4f4f4;
            }
            h1 {
                color: darkblue;
                text-align: center;
            }
            p {
                color: gray;
                font-size: 16px;
            }
        </style>
    </head>
    <body>
        <h1>Welcome to My Website</h1>

        <!-- Inline CSS: Applied directly to the element -->
        <p style="color: red; font-weight: bold;">This paragraph uses inline CSS.</p>

        <p>This paragraph uses internal and external CSS rules.</p>
    </body>
</html>

3. Combining HTML and CSS

  • How HTML and CSS Work Together:
    • CSS styles are applied to HTML elements by referencing them in the CSS.
    • Example of linking an external CSS file: 
      <head>
    <link rel="stylesheet" href="styles.css">
</head>
  • How to Break Apart Files:
    • Discuss the separation of concerns: HTML for structure, CSS for style.
    • Example: Move inline or internal CSS to an external file for reusability and maintainability.

4. Introduction to Google Chrome DevTools

Google Chrome DevTools is a set of tools built directly into the Chrome browser. It allows developers to inspect, debug, and optimize web pages by providing access to the underlying HTML, CSS, and JavaScript.

  • Accessing DevTools:
    • Right-click on any element on a webpage and select Inspect.
    • Or use the shortcut Cmd + Option + I on Mac, or Ctrl + Shift + I on Windows/Linux.
    • This opens the DevTools panel, where you can navigate to tabs like Elements, Console, and Sources.

5. Inspecting Elements (Elements Panel)

The Elements Panel is where you can see the structure of an HTML page and inspect or modify the elements and styles.

  • Key Features:
    • View HTML Structure: On the left, you can see the document's HTML elements organized in a nested structure. This reflects the actual Document Object Model (DOM) of the page.
    • View CSS Styles: On the right, you'll see the applied CSS styles, including where each style comes from (internal styles, external stylesheets, inline styles).
    • Edit HTML and CSS on the Fly: You can modify the HTML and CSS directly within DevTools to see how changes affect the page in real time.
  • Exercise:
    • Inspect a heading element (<h1>) and modify its color directly in DevTools to see the immediate effect. Look for a section called element.style and between the { } add color: red;
    <h1>Welcome to My Website</h1>

Steps to Follow:

  1. Right-click on the heading in the browser and choose Inspect.
  2. In the Elements panel, find the h1 tag and click on it.
  3. On the right, under the Styles pane, find the CSS rules applied to the h1 tag.
  4. Modify the color property in the Styles pane and watch the heading change color in real time.

6. Introduction to JavaScript

  • What is JavaScript?
    • JavaScript is the programming language of the web, used to add interactivity and logic to HTML and CSS.
    • Key concept: JavaScript can manipulate HTML and CSS via the DOM (Document Object Model).
  • JavaScript in HTML:
    • Inline JavaScript vs. internal (within <script> tags) vs. external (using .js files).
    • Ensure that <script> tags are located just before the closing </body> tag of your HTML page, so the script is the last thing read after the whole page has loaded.
    • Example of adding JavaScript in HTML: 
      <script>
    document
        .querySelector("h1")
        .style
        .color = "red";
</script>
  • Event Listeners and DOM Manipulation:
    • JavaScript can respond to user interactions (e.g. button clicks) using event listeners.
    • Example: Add a button that changes a heading's color: 
      document
    .getElementById("myButton")
    .addEventListener("click", function() {
        document
            .querySelector("h1")
            .style
            .color = "green";
    });

7. Using the Console for JavaScript (Console Panel)

The Console panel lets you run JavaScript directly in the browser and check for errors or output from your scripts.

  • Key Features:
    • Execute JavaScript: Write JavaScript directly in the console and see the results instantly.
    • Check for Errors: Any JavaScript errors on the page are logged in the console.
    • Logging Information: Use console.log() in your JavaScript to print messages or variables to the console.
  • Exercise:
    • Open the Console (Cmd + Option + J on Mac, or Ctrl + Shift + J on Windows/Linux) and run: 
      document
    .querySelector("h1")
    .style
    .color = "blue";
    • This command instantly changes the color of the <h1> element to blue, showing how JavaScript can dynamically interact with the DOM.
  • Testing Event Listeners:
    • Use the console to test the event listener you created in class. For example: 
      document
    .getElementById("colorButton")
    .addEventListener("click", function() {
        console.log("Button clicked!");
        // This logs a message every time the button is clicked
    });
    • When clicking the button, you will see "Button clicked!" appear in the console.
