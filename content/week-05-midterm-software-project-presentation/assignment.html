Part 2: Hardware Check

Next week is the first hardware class. Everything below has to be on your desk before you walk in.

  1. Common kit: Arduino UNO R4 WiFi, the BOJACK component kit, and a USB-C cable that carries data.
  2. Project parts: open the parts list you ordered in Week 3. Tick off what has arrived. For anything still missing, check the delivery date and reorder from another supplier if it lands after Week 7.
  3. Safety glasses: clear, impact-rated (marked ANSI Z87.1). You will not be allowed to solder without them.
  4. Board test: plug the UNO R4 into your laptop, open the Arduino IDE, choose File > Examples > 01.Basics > Blink and upload it. If the IDE asks to install the Arduino UNO R4 Boards package, say yes. The on-board LED should blink once a second.
    • If the board does not show up, try another USB-C cable first. Charge-only cables are the most common cause.

Part 3: Start Moving Your Interface to React (step 1 of 3)

Your project interface needs to be a React app by Week 7, when it starts talking to your Arduino. You already did this conversion once with the Number Adder, so we split it into three small steps over three weeks.

This week, layout only:

  1. In week 5/Project, create a new Vite React app, the same way as in Week 4.
  2. Clear Vite's starter CSS and paste in your project's CSS.
  3. Split your page into components (for example a header, a control panel, a status panel). Each one in its own .jsx file.
  4. It should look like your current interface. It does not need to work yet: no state, no clicks.

Step 2 (Week 6) adds state so it works again. Step 3 (Week 7) connects it to your Arduino.
