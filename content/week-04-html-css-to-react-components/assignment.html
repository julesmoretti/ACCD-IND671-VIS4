Assignment Overview: Enhanced Number Adder with React and Redux

The goal of this Week 4 assignment is to convert your Week 3 Number Adder project into a React application using Redux for state management. You will implement a counter with a history of operations, similar to Week 3, but managed through Redux actions and components.

Objectives:

  1. Create a React web page that matches or improves upon the appearance of your Week 3 page.
    • Bonus: Enhance the CSS to improve the visual design.
  2. Implement all Week 3 functionality using Redux, including:
    • Adding values (+1, +2) and subtracting values (-1, -2) to a counter, tracked in the Redux store’s count and history.
    • Resetting the counter and appending RESET to the history (replacing the Week 3 checkTotal() and reset functionality).
    • Removing individual history items by clicking them in the history list, using the UPDATE_HISTORY Redux action.
    • Clearing the history and results, which can be implemented as a new CLEAR_ALL Redux action.
  3. Bonus Feature: Enhance the history removal functionality to update the count based on the removed item (e.g., removing a 1 subtracts 1 from count, removing a -2 adds 2 to count).

Resources:

  • Two video recordings are available on this canvas page to guide you through setting up React-Redux and implementing the required functionality.
  • Refer to the Redux documentation page for code examples, including the Redux store setup and the ResultBar and ControlCenter components.

Implementation Details

Redux Store:

  • Create a Redux store in src/store.js with a state containing count (the total) and history (an array of operations like 1, -2, RESET).
  • Define actions: ADD_1, ADD_2, REMOVE_1, REMOVE_2, RESET, and UPDATE_HISTORY (for removing a history item by index).
  • For the bonus feature, modify the UPDATE_HISTORY action to adjust count based on the removed item’s value.

Components:

  • ControlCenter: A component with buttons to dispatch ADD_1, ADD_2, REMOVE_1, REMOVE_2, and RESET actions. Implement a CLEAR_ALL action for the "Clear History & Results" button to reset both count and history.
  • ResultBar: A sidebar component that displays count and renders history as a clickable list. Clicking a history item dispatches UPDATE_HISTORY with the item’s index to remove it.
  • For the bonus feature, use useEffect in ResultBar to update elements like totalMessage or summary when count or history changes (e.g., to display a message or summary of operations).
