There are 3 parts to this assignment:

Part 1 (20 minutes)

In GitHub, create a new repo called vis4. Within this repo, create a folder for each week, starting with week 2. Once you have done this, commit and push your changes, then send me your repo address on Slack through the group.

Part 2 (1.5 hours)

Start reading the Week 2 document, and watch the supporting video material that walks through that reading page if you need support. Feel free to play the video back at 1.5x, otherwise it will take too long.

By the end of the reading document you should have created 2 files: one HTML file and a style.css file.

Make sure these files live in your GitHub repo under week 2 > Reading.

NOTE: Feel free to work with your classmates to figure these steps out. Collaboration is key in the professional context.

Part 3 (1 hour) — Choose your project

Everything you build this term attaches to one project, and you choose it this week.

Pick a project you have already designed in a studio course. Something that was resolved as an object — form, material, intent — but was never resolved as an interaction. Most studio work assumes the thing works. This term you make it work, and then find out whether it works for anyone else.

Name your hero experience

You are not building the whole product. You are building the one interaction that matters most — the thing your device exists to do.

Write it in one sentence. For example:

The user sets a target number of turns, starts the winder, and it stops itself when it reaches the target.

That single sentence drives everything: the interface you start building next week, the electronics you buy, the HMI document in Week 8, and what gets tested three times in the second half of term. Breadth is worth less here than one interaction that genuinely works.

Order your common kit

Order the common hardware kit this week. Every student needs the same one, the list is on the course page, and it runs about $150.

Do this now, not later. Component lead time was the single biggest problem reported by last year's class — students who ordered late lost build weeks waiting for parts to arrive. Your project-specific components get identified in Week 4, but the common kit is what you learn on in Week 6, and it needs to be on your desk by then.

If you do not have a suitable project

Come and talk to me this week rather than next. There are a couple of house projects available — including a rubber band winder and counter for the rubber-band-powered car class — that work well for this course.

  3. Your chosen project and hero experience sentence, posted to Slack — one or two lines plus an image of the original studio project.
  4. Confirmation that your common kit is ordered.
