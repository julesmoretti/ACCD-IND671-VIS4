Installation of Software for Apple Computers (Mac)

NOTE: A video recording of the steps to follow has been added to your Modules section for Mac specifically.

NOTE: Several of these apps are downloaded outside the App Store. The first time you open each one, macOS will ask "is an app downloaded from the Internet. Are you sure you want to open it?". Click Open. Always move an app into your Applications folder before opening it for the first time.

NOTE: Before you start, check which chip your Mac has: click the Apple menu > About This Mac and look at the Chip line (Apple M-series, or Intel). You will need this for the Arduino IDE download.

Homebrew

Within Terminal, copy and paste /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)" and press return. You will be asked for your Mac password (nothing appears while you type it, that is normal), then to press RETURN to continue. On a Mac that has never had developer tools installed, Homebrew will first install the Xcode Command Line Tools, which can take 5 to 15 minutes.

When it finishes with Installation successful!, close Terminal completely (Command + Q) and reopen it so that the brew command is available.

Node.js

After installing Homebrew, copy and paste brew install node into Terminal and press return. Homebrew will list what it is about to install and ask Do you want to proceed with the installation? [y/n]. Type y and press return.

To check it worked, run node -v and npm -v. Each should print a version number.

Dash

To install Dash, go to kapeli.com/dash and click Download. This downloads Dash.zip. Double-click it to unzip it, then drag Dash.app into your Applications folder before opening it.

Dash is free to use for this course. It shows a Purchase Dash banner and, after the 30-day trial, adds short delays when searching. You do not need to buy it.

Open Dash and click Download Docsets. Use the search field to find and download the following libraries:

  • JavaScript
  • Arduino
  • React
  • CSS
  • HTML
  • Optional:
    • Node.js
    • Bootstrap 5

The Arduino docset is large (about 135 MB). Start the downloads and carry on with the next steps while they finish.

Sublime Text Editor

Go to sublimetext.com and click Download for Mac. This downloads a file named sublime_text_build_XXXX_mac.zip. Double-click it to unzip it, then drag Sublime Text.app into your Applications folder before opening it.

In Terminal, copy and paste the following (you will be asked for your Mac password):

sudo mkdir -p /usr/local/bin
sudo ln -sf "/Applications/Sublime Text.app/Contents/SharedSupport/bin/subl" /usr/local/bin/subl

This creates a shortcut so you can open Sublime Text from Terminal, for example with subl .

To check it worked, run subl --version. It should print Sublime Text Build XXXX.

In order to test JavaScript files inside Sublime Text you will need to create a new build system. With Sublime Text open, click Tools > Build System > New Build System. This opens a new file. Replace all of the content with:

// Sublime Text - Build System for JavaScript
{
    "cmd": ["node", "$file"],
    "selector": "source.js"
}

Press Command + S, name the file JavaScript.sublime-build, keep the folder Sublime suggests (it is the correct one), save, and close the file.

To test whether that worked, press Command + N for a new file, add console.log("This is a test"); and save it as test.js somewhere easy to find, such as your Desktop.

Make sure the build system is selected under Tools > Build System > JavaScript.

Press Command + B and you should get the output This is a test at the bottom.

Arduino IDE

Go to arduino.cc/en/software. In the dropdown next to the DOWNLOAD button, choose macOS Apple Silicon or macOS Intel to match your chip (see the note at the top of this section), then click DOWNLOAD. Open the downloaded .dmg file and drag Arduino IDE.app onto the Applications shortcut next to it.

Open the Arduino IDE from your Applications folder. After the usual "downloaded from the Internet" prompt, macOS will ask whether to allow Arduino IDE to find devices on local networks. Click Allow. Once it is open, eject the installer disk that appeared on your Desktop (click it and press Command + E).

Optional but recommended: the board we use later in the term needs an extra package that is a large download. To get it out of the way now, in the Arduino IDE go to Tools > Board > Boards Manager, search for UNO R4, and install Arduino UNO R4 Boards.

GitHub Signup and Configuration (OPTIONAL)

Go to github.com and create a new account with your personal or ArtCenter email (choose depending on whether you want to keep the account after ArtCenter).

Once created, you will need to bind your Mac to your GitHub profile.

NOTE: Make sure to replace the email address with the one you used for your GitHub account in the next step.

Create an SSH key in Terminal using ssh-keygen -t ed25519 -C "your@emailaddress.com". It asks three questions (where to save the key, a passphrase, and the passphrase again). Press Return for all three, without typing anything.

Open github.com/settings/keys in your browser and click the green New SSH key button. In the Title field, type a name describing the machine the key was created on (for example MacBook 2026). Leave Key type as Authentication Key.

Now go back to Terminal and copy the key to your clipboard with pbcopy < ~/.ssh/id_ed25519.pub. Do this as the very last step before pasting: anything else you copy afterwards will replace the key in your clipboard.

Return to the browser, click inside the Key field, press Command + V, and click Add SSH key. GitHub may ask you to confirm your password.

To test that the key is working, in Terminal run ssh -T git@github.com. The first time you connect you will be asked "Are you sure you want to continue connecting (yes/no/[fingerprint])?". Type yes and press return. You should then see:

Hi yourusername! You've successfully authenticated, but GitHub does not provide shell access.

If instead you see Permission denied (publickey), the key was not added to your GitHub account correctly. Go back to github.com/settings/keys and check that your key is listed, then repeat the pbcopy and paste steps.

Finally, test cloning a repository. Move into the folder where you want to keep your course work (for example cd ~/Documents), then run git clone git@github.com:julesmoretti/ACCD-Fritzing-Parts.git. If successful you should see output similar to:

Cloning into 'ACCD-Fritzing-Parts'...

remote: Counting objects: 100% (123/123), done.
remote: Compressing objects: 100% (88/88), done.

Installation of Software for Windows Machines

NOTE: Each installer below opens a Windows User Account Control prompt ("Do you want to allow this app to make changes to your device?"). Click Yes. Some also ask you to accept a license agreement; accept it.

Node.js

To download Node.js, go to the Node.js download page. Leave the version dropdown on the default LTS release and the platform on Windows / x64, then click Windows Installer (.msi). Run the downloaded file (named like node-v24.21.0-x64.msi).

Click Next through the installer, accepting the license and the default folder. On the Tools for Native Modules screen, leave the checkbox Automatically install the necessary tools unchecked (it installs several gigabytes of build tools that this course does not use). Click Next, Install, then Finish.

To check it worked, open a new PowerShell window (Start menu, type PowerShell) and run node -v and npm -v. Each should print a version number. If you get "not recognized", close PowerShell and open a new one.

Sublime Text Editor

Go to the Sublime Text download page and click Windows. This downloads a file named like sublime_text_build_4200_x64_setup.exe. Run it, keep the default folder, and on the Select Additional Tasks screen tick Add to explorer context menu (this gives you a right-click "Open with Sublime Text" option on any folder). Click Install, then Finish.

In order to test JavaScript files inside Sublime Text you will need to create a new build system. With Sublime Text open, click Tools > Build System > New Build System. Replace all of the content with:

// Sublime Text - Build System for JavaScript
{
    "cmd": ["node", "$file"],
    "selector": "source.js"
}

Press Control + S, name the file JavaScript.sublime-build, keep the folder Sublime suggests (it is the correct one), save, and close the file.

To test whether that worked, press Control + N for a new file, add console.log("This is a test"); and save it as test.js somewhere easy to find, such as your Desktop.

Make sure the build system is selected under Tools > Build System > JavaScript.

Press Control + B and you should get the output This is a test at the bottom.

Arduino IDE

Go to arduino.cc/en/software. In the dropdown next to the DOWNLOAD button make sure Windows Win 10 or newer (64-bit) is selected, then click DOWNLOAD. Run the downloaded file (named like arduino-ide_2.3.10_Windows_64bit.exe).

Click I Agree, keep Only for me selected (this avoids needing administrator rights), keep the default folder, click Install, then Finish with Run Arduino IDE ticked.

On first launch Windows may show one or two security prompts asking whether to allow the Arduino IDE (for example a Windows Defender Firewall "Allow access" dialog). Click Allow on each.

Optional but recommended: the board we use later in the term needs an extra package that is a large download. To get it out of the way now, in the Arduino IDE go to Tools > Board > Boards Manager, search for UNO R4, and install Arduino UNO R4 Boards.

Git Install (OPTIONAL)

Go to git-scm.com/install/windows and click the Click here to download link at the top of the page (the x64 version). Run the downloaded file (named like Git-2.55.0.5-64-bit.exe).

The installer has many screens. Keep the pre-selected option on every screen and click Next, with these exceptions:

  • Select Components: also tick Add a Git Bash Profile to Windows Terminal.
  • Choosing the default editor used by Git: change the dropdown from Vim to Use Sublime Text as Git's default editor.
  • Adjusting the name of the initial branch: select Override the default branch name for new repositories and leave the name as main.

Everything else stays on its default (PATH: "Git from the command line and also from 3rd-party software"; bundled OpenSSH; line endings: "Checkout Windows-style, commit Unix-style"; MinTTY; Merge; Git Credential Manager). Click Install, then Finish.

Open Git Bash from the Start menu and run git -v, which returns the git version.

NOTE: In Git Bash, Control + V does not paste (it inserts garbage characters). Paste with right-click > Paste or Shift + Insert, or type the commands. Control + V still works normally in your browser.

Getting the subl shortcut working from Git Bash

To open Sublime Text from Git Bash with subl ., run the following three lines in Git Bash (type them or paste with right-click):

echo "alias subl='/c/Program\ Files/Sublime\ Text/subl.exe'" >> ~/.bashrc
source ~/.bashrc
subl --version

The last line should print Sublime Text Build XXXX.

That concludes the Windows configuration for your machine.

GitHub Desktop (Mac and Windows)

GitHub Desktop is the visual interface we use in class for committing and pushing, so you do not have to type git commands every week. Install it after the GitHub steps above, on either platform.

Go to desktop.github.com/download and download the version for your operating system. On Mac, unzip and move GitHub Desktop.app to your Applications folder before opening it. On Windows, run the installer.

Open GitHub Desktop and sign in to your GitHub account when prompted (File > Options > Accounts on Windows, GitHub Desktop > Settings > Accounts on Mac, if the prompt does not appear).

GitHub Desktop does not know about the repository you cloned from Terminal or Git Bash. Add it manually: File > Add Local Repository, then Choose and select the ACCD-Fritzing-Parts folder you cloned earlier. It should now appear in the top-left repository list.

Finally, set Sublime Text as the editor GitHub Desktop opens files with. In the main window, the button in the middle says Open in Visual Studio Code or Open in Sublime Text. If it says Visual Studio Code, go to File > Options (Windows) or GitHub Desktop > Settings (Mac), open the Integrations tab, and set External Editor to Sublime Text. If Sublime Text is not in the list, quit and reopen GitHub Desktop; it only scans for editors on launch.

Common hardware kit (order this week)

Every student needs the same two items. Order them this week; they need to be on your desk by Week 6. Project-specific components come later, in Week 4.

  • Arduino UNO R4 WiFi (ABX00087) — the official board. Do not substitute a clone or a different UNO; the WiFi model is required for the WebSocket work in the second half of the term.
  • BOJACK 37 Values 480 Pcs Electronics Component Fun Kit — breadboard, power supply module, jumper wires, potentiometer, resistors, LEDs and the other parts we use in Weeks 6 and 7. Any equivalent kit with an 830 tie-point breadboard, jumper wires, resistors, LEDs and a potentiometer is acceptable.

You will also need a USB-C cable that carries data (not charge-only) to connect the UNO R4 to your laptop. Most phone cables work; if the board does not show up in the Arduino IDE in Week 6, the cable is the first thing to check.
