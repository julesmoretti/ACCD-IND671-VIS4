Installation of Software for Apple Computers (Mac)

NOTE: A video recording of the steps to follow has been added to your Modules section for Mac specifically.

Homebrew

Within Terminal, copy and paste /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)" and press enter. You may need administrative rights to do this.

Node.js

After installing Homebrew, copy and paste brew install node into Terminal and press return.

Dash

To install Dash, go to kapeli.com/dash, click download, unzip the downloaded file, and drag and drop it into your Applications folder.

Open Dash and download the following libraries:

  • JavaScript
  • Arduino
  • React
  • CSS
  • HTML
  • Optional:
    • Node.js
    • Bootstrap 5

Sublime Text Editor

Go to sublimetext.com, click the download tab, and click macOS. Unzip the app and drag and drop the application into your Applications folder.

In Terminal, copy and paste the following:

sudo mkdir /usr/local/bin
sudo ln -s "/Applications/Sublime Text.app/Contents/SharedSupport/bin/subl" /usr/local/bin/subl

This creates a shortcut so you can open Sublime Text from Terminal, for example with subl .

In order to test JavaScript files inside Sublime Text you will need to create a new build system. With Sublime Text open, click Tools > Build System > New Build System. This opens a new file. Replace all of the content with:

// Sublime Text - Build System for JavaScript
{
    "cmd": ["node", "$file"],
    "selector": "source.js"
}

Save the file as JavaScript.sublime-build and close it.

To test whether that worked, create a new file and save it as test.js. Inside the file, add console.log("This is a test"); and save.

Make sure the build system is selected under Tools > Build System > JavaScript.

Press Command + B and you should get the output This is a test at the bottom.

Arduino IDE

Go to arduino.cc/en/software and download the appropriate macOS app for your machine. Click JUST DOWNLOAD. Open the downloaded file and drag and drop it into your Applications folder.

GitHub Signup and Configuration (OPTIONAL)

Go to github.com and create a new account with your personal or ArtCenter email (choose depending on whether you want to keep the account after ArtCenter).

Once created, you will need to bind your Mac to your GitHub profile.

Create an SSH key in Terminal using ssh-keygen -t ed25519 -C "your@emailaddress.com"

Then copy it to your clipboard with pbcopy < ~/.ssh/id_ed25519.pub

Go to github.com/settings/keys without losing the copied content, click the green New SSH key button, and add a title describing the machine the key was created on. Paste the copied key into the key field and click Add SSH key.

To test that this is working, open Terminal and run git clone git@github.com:julesmoretti/ACCD-IND671-VIS4.git. If successful you should see output similar to:

Arduino IDE

Git Install (OPTIONAL)

Go to git-scm.com/download/win and click 64-bit Git for Windows Setup. Run the installer. Feel free to launch Git Bash at the end and test git by typing git -v, which returns the git version.

GitHub Signup and Configuration (OPTIONAL)

Go to github.com and create a new account with your personal or ArtCenter email (choose depending on whether you want to keep the account after ArtCenter).

Once created, you will need to bind your Windows machine to your GitHub profile.

NOTE: Make sure to replace the email address with the one you used for your GitHub account in the next step.

Create an SSH key in Git Bash using ssh-keygen -t ed25519 -C "your_email@example.com". Keep pressing Return or Enter until it completes, without entering a filename or passphrase.

To copy the SSH key, in the same Git Bash window run clip < ~/.ssh/id_ed25519.pub and press return. This copies your SSH key to the clipboard.

Go to github.com/settings/keys without losing the copied content, click the green New SSH key button, and add a title describing the machine the key was created on. Paste the copied key into the key field and click Add SSH key.

To test that this is working, open Git Bash and run git clone git@github.com:julesmoretti/ACCD-IND671-VIS4.git. If successful you should see output similar to:

remote: Compressing objects: 100% (4/4), done.

Getting the subl shortcut working from Git Bash

To get your subl shortcut working, follow these instructions, with the exception that the line to paste into your .bashrc should point at your installed version:

alias subl='C:/Program\ Files/Sublime\ Text/sublime_text.exe'

That concludes the Windows configuration for your machine.
