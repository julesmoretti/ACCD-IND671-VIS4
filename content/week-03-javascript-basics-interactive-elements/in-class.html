Starter: Your Project Parts List (15 min)

Parts take weeks to arrive, and late parts were the biggest problem last year. Start your list now, finish it for homework, and place your order by Thursday.

  1. Write down your hero experience in one sentence.
  2. List what the device needs to make it happen:
    • Inputs — what it senses (buttons, dials, sensors)
    • Outputs — what it does (motors, LEDs, sound, display)
    • Power — USB, battery, or wall supply
    • Mechanical — anything that holds, moves or connects parts
  3. Cross off anything already in the common kit (UNO R4 WiFi + BOJACK kit from Week 1).
  4. For everything left, record: part, quantity, link, price, delivery date. If a delivery date is after Week 6, find another supplier.

Setup: In your vis4 repo, create week 3/In-Class/index.html with a <script> block just before </body>. Write Exercises 1–4 inside that script, open the page in Chrome, and watch the results in the Console (Cmd + Option + J / Ctrl + Shift + J). Exercise 5 goes back to your Week 2 Number Adder.

Exercise 1: Manipulating Variables and Data Types

  1. Objective: Declare and manipulate different types of variables, including arrays and objects.
  2. Instructions:
    • Declare variables for a person's name, age, and hobbies (using an array).
    • Log these variables to the console
    • Add a new hobby to the array using .push() and log the outcome to see what happened.
    • log a specific index of the array using hobbies[index_number]
    • Remove the last added hobby of the array using .pop() and log the outcome of the array.
    • Extract a section of the array using .slice(start_index, end_index) and log that.
    • Group all three into one object: let person = { name: name, age: age, hobbies: hobbies };. Then add one to the age with person.age = person.age + 1; and log person.
  3. Example Code 
    let name = "John";
let age = 25;
let hobbies = ["football", "reading"];

console.log(name, age, hobbies);

// Adding a new hobby
hobbies.push("gaming");
console.log(hobbies);
  4. Expected Outcome: Students will see how variables and arrays are manipulated, including using array methods like push().

Exercise 2: Creating and Using Functions

  1. Objective: Create a function that accepts parameters, processes input, and returns a result.
  2. Instructions:
    • Create a function calculateAgeInDays that takes a person's age and returns their age in days.
    • Call the function with different ages and log the result to the console.
    • Rewrite the function in ES6 format using arrow operator =>.
  3. Example Code: 
    function calculateAgeInDays(age) {
    return age * 365;
}

console.log(calculateAgeInDays(25)); // 9125

console.log(calculateAgeInDays(30)); // 10950
  4. Expected Outcome: Students should be able to learn how to define functions and use them to process data.

Exercise 3: Demonstrating Scope

  1. Objective: Understand the difference between local and global scope by manipulating variables inside and outside functions.
  2. Instructions:
    • Declare a global variable.
    • Create a function that declares a local variable and accesses both local and global variables.
  3. Example Code: 
    let globalVar = "I am global";

function testScope() {
    let localVar = "I am local";
    
    console.log(globalVar); // Accessing global variable
    console.log(localVar); // Accessing local variable
}

testScope();
console.log(localVar); // This will throw an error (localVar is not accessible here)
  4. Important: once you have seen the error in the Console, comment out that last line (// console.log(localVar);). An error stops the rest of the script, so Exercise 4 will not run until you do.
  5. Expected Outcome: Students should be able to see the importance of scope and how variables are accessed based on where they are declared.

Exercise 4: Loops and Conditionals

  1. Objective: Use loops and conditional statements to process arrays and make decisions in the code.
  2. Instructions:
    • Create an array of numbers.
    • Write a for loop that iterates through the array and checks if each number is even or odd using an if-else statement.
  3. Example Code: 
    let numbers = [1, 2, 3, 4, 5, 6];
for (let i = 0; i < numbers.length; i++) {

    if (numbers[i] % 2 === 0) {
        console.log(numbers[i] + " is even");
    } else {
        console.log(numbers[i] + " is odd");
    }

}
  4. Expected Outcome: Students should understand how to iterate over arrays and use conditionals to perform different actions based on conditions.
