Introduction

This week we are going to learn JavaScript fundamentals such as variables, data types, loops, functions, and more.

Part 1: Walkthrough / Discussion

1. Introduction to Variables and Data Types

  • Overview: Variables are used to store data. JavaScript supports multiple data types, including strings, numbers, booleans, objects, and arrays.
  • Variable Declaration:
    • var, let, and const (briefly mention hoisting and the difference between var and let/const).
    • Example: 
      let name = "Alice";   // String
const age = 30;       // Number
var isStudent = true; // Boolean
  • Data Types:
    • Primitive Types: String, Number, Boolean, Null, Undefined.
    • Objects: Arrays and Objects.
    • Example: 
      const person = {
    name: "Alice",
    age: 30,
    hobbies: ["reading", "hiking", "coding"]
};

console.log(person.name); // Accessing object property

2. Functions and Parameters

  • Overview: Functions encapsulate reusable blocks of code. They can accept parameters (input values) and return results.
  • Defining Functions:
    • Function declaration: 
      function greet(name) {
    return "Hello, " + name;
}
    • Arrow function (ES6): 
      const greet = (name) => "Hello, " + name;
  • Passing Parameters:
    • Functions can take multiple developer-defined parameters and return a result.
    • Example: 
      function add(a, b) {
    return a + b;
}

3. Scope in JavaScript

  • Overview: Scope refers to the visibility of variables within different parts of the code. Variables defined inside a function are local to that function, while variables defined outside have global scope.
  • Local vs Global Scope:
    • Local variables are accessible only within the function where they are declared.
    • Global variables can be accessed from anywhere in the code.
    • Example: 
      let globalVar = "I am global";

function showScope() {
    let localVar = "I am local";
    console.log(globalVar); // Can access globalVar
    console.log(localVar);  // Can access localVar
}

showScope();
console.log(localVar); // Error: localVar is not defined

4. Loops and Conditional Statements

  • Overview: Loops allow for repeating blocks of code, and if statements are used for conditional logic.
    • For Loop: A common loop for iterating over arrays or running code multiple times, but not typically indefinitely.
    • Example: 
      for (let i = 0; i < 5; i++) {
    console.log(i);
}
    • if-else Statements: if statements are used for conditional checks. They execute a block of code if a condition is true, and optionally another block if it is false.
    • Example: 
      if (age >= 18) {
    console.log("You are an adult.");
} else {
    console.log("You are a minor.");
}
