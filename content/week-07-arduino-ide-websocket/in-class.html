Exercise 3: Potentiometer (10 min)

Build reading Step 5. Turn the knob and watch the value go from 0 to 1023 in the Serial Monitor.

Exercise 4: Run the WebSocket Example (40 min)

  1. Start the server (reading Step 6b). Write down the IP address it prints.
  2. Create and run the React app (Step 6c). The connection status should read Open.
  3. Put that IP address and your WiFi details into the Arduino sketch (Step 6d) and upload it.
  4. Turn the potentiometer: the value should update in the React app. Click Add 1 LED: an LED should light on the board's matrix.

If it does not connect: laptop and Arduino must be on the same WiFi network, the server must be running first, and the IP in the sketch must match the one the server printed.

Exercise 5: Connect Your Number Adder (40 min)

Now use the same server with your Week 4 React Number Adder. A physical button adds 1, and the board's LED matrix shows the total.

Arduino side

Wire a button between pin 2 and GND (no resistor needed: we use the board's internal pull-up). Add to the Step 6d sketch:

const int buttonPin = 2;
int lastButtonState = HIGH;

// in setup():
pinMode(buttonPin, INPUT_PULLUP);

// in loop(), after the message-reading block:
int buttonState = digitalRead(buttonPin);
if (buttonState == LOW && lastButtonState == HIGH) {   // just pressed
  client.beginMessage(TYPE_TEXT);
  client.print("{\"button\": \"+1\"}");
  client.endMessage();
  delay(50);                                           // ignore switch bounce
}
lastButtonState = buttonState;

React side

In your Week 4 Number Adder, run npm install react-use-websocket, then in App.jsx:

import { useState, useEffect } from 'react';
import useWebSocket from 'react-use-websocket';

// inside App(), after your useState lines:
const { sendMessage, lastMessage } = useWebSocket('ws://localhost:8080');

useEffect(() => {
  if (lastMessage === null) return;
  try {
    const data = JSON.parse(lastMessage.data);
    if (data.button === '+1') {
      handleAddOne();
    }
  } catch (error) {
    // not JSON, ignore it
  }
}, [lastMessage]);

Then, inside handleAddOne(), add sendMessage('ADD_1_LED');, and inside handleRemoveOne(), add sendMessage('REMOVE_1_LED');.

Test both directions: the physical button changes the total on screen, and the on-screen buttons change the LED matrix.
