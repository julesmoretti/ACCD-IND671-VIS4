Today you build your first working prototype end to end: buttons on your breadboard work your React Number Adder, and the Number Adder shows its total on the Arduino's LED matrix. Part 1 you follow along with me, step by step. Part 2 you do on your own.

Before We Start

  • Bring: your laptop with the React Number Adder from Week 4, your UNO R4 WiFi and a USB-C cable that carries data, your BOJACK kit (breadboard, 5 push buttons, an LED, a 1 kΩ resistor, a potentiometer, jumper wires).
  • Network: your laptop and your Arduino both join the campus WiFi. I give you the network name and password in class.

How It Fits Together

Arduino  <--WiFi-->  server (on your laptop)  <-->  React Number Adder (in your browser)

device to screen:   {"button": "+1"}   a physical button works the Number Adder
screen to device:   TOTAL:5            the LED matrix shows the total

The Arduino and the React app never talk to each other directly. Both connect to a small server on your laptop, and the server passes each message on.

F5. The Server on Your Laptop (10 min)

  1. In a terminal, inside your vis4/week 7 folder: 
    mkdir WSServer
cd WSServer
npm init -y
npm install ws
touch server.js
subl server.js
  2. Paste this into server.js and save: 
    const os = require('os');
const WebSocket = require('ws');

const port = 8080;
const wss = new WebSocket.Server({ port });

// Find this laptop's IP address on the WiFi, so the Arduino knows where to connect
function localIP() {
  for (const addresses of Object.values(os.networkInterfaces())) {
    for (const a of addresses) {
      if (a.family === 'IPv4' && !a.internal) return a.address;
    }
  }
  return 'localhost';
}

wss.on('connection', function connection(ws) {
  console.log('connected');

  ws.on('message', function incoming(message) {
    const text = message.toString();
    console.log('received:', text);

    // Pass the message on to everyone else who is connected
    wss.clients.forEach((client) => {
      if (client !== ws && client.readyState === WebSocket.OPEN) {
        client.send(text);
      }
    });
  });

  ws.on('close', function () {
    console.log('disconnected');
  });
});

console.log(localIP() + ' listening on port', port);
  3. Start it with node server.js. It prints an IP address, for example 192.168.1.15 listening on port 8080. Write that IP down: the Arduino needs it. Leave this terminal running.

F6. The Arduino Joins (15 min)

  1. Install the ArduinoHttpClient library first. Click the Library Manager (the books icon in the left sidebar), search ArduinoHttpClient, and install the one by Arduino. Skip this and the upload fails with "ArduinoHttpClient.h: No such file or directory".
  2. Rewire the button for the built-in resistor: remove the F3 resistor and the wire to 5V. The button goes across the centre gap, one leg to pin 2, the diagonal leg to the − rail, and the − rail to GND. The sketch below turns the pin's resistor on with INPUT_PULLUP.
  3. Start a new sketch called NumberAdderDevice. Add a second tab (the small arrow at the right of the tabs, New Tab) named arduino_secrets.h: 
    #define SECRET_SSID "campus network name"
#define SECRET_PASS "campus network password"
  4. Paste this into the main tab and change serverAddress to the IP your server printed: 
    // Number Adder device: five buttons work the Number Adder on screen,
// and the LED matrix shows the total.
#include <ArduinoHttpClient.h>
#include <WiFiS3.h>
#include "Arduino_LED_Matrix.h"
#include "arduino_secrets.h"

char ssid[] = SECRET_SSID;
char pass[] = SECRET_PASS;
char serverAddress[] = "192.168.1.23";  // change to the IP your server printed
int port = 8080;

WiFiClient wifi;
WebSocketClient client = WebSocketClient(wifi, serverAddress, port);
ArduinoLEDMatrix matrix;
uint8_t frame[8][12];

// Same order as the buttons on screen, left to right
const int buttonPins[5] = {2, 3, 4, 5, 6};
const char* buttonNames[5] = {"-2", "-1", "reset", "+1", "+2"};
int lastStates[5] = {HIGH, HIGH, HIGH, HIGH, HIGH};

int total = 0;

void setup() {
  Serial.begin(9600);
  matrix.begin();
  for (int i = 0; i < 5; i++) {
    pinMode(buttonPins[i], INPUT_PULLUP);  // HIGH when released, LOW when pressed
  }

  while (WiFi.begin(ssid, pass) != WL_CONNECTED) {
    Serial.println("Connecting to WiFi...");
    delay(1000);
  }
  delay(2000);  // give the board time to get its IP address
  Serial.print("WiFi connected. Arduino IP: ");
  Serial.println(WiFi.localIP());
  client.begin();
}

void loop() {
  // Keep the connection to the server open
  if (!client.connected()) {
    Serial.println("Connecting to server...");
    client.begin();
    delay(1000);
    return;
  }

  // Screen -> device: the React app sends "TOTAL:5"
  if (client.parseMessage() > 0) {
    String message = client.readString();
    Serial.println("Received: " + message);
    if (message.startsWith("TOTAL:")) {
      total = message.substring(6).toInt();
      showTotal();
    }
  }

  // Device -> screen: one message per press, per button
  for (int i = 0; i < 5; i++) {
    int state = digitalRead(buttonPins[i]);
    if (state == LOW && lastStates[i] == HIGH) {
      sendButton(buttonNames[i]);
      delay(50);  // ignore switch bounce
    }
    lastStates[i] = state;
  }
}

// Sends {"button": "+1"} and so on
void sendButton(const char* name) {
  client.beginMessage(TYPE_TEXT);
  client.print("{\"button\": \"");
  client.print(name);
  client.print("\"}");
  client.endMessage();
  Serial.print("Sent: ");
  Serial.println(name);
}

// One LED per point: positive totals fill from the start of the matrix,
// negative totals fill backwards from the end
void showTotal() {
  memset(frame, 0, sizeof(frame));
  int count = min(abs(total), 96);
  for (int i = 0; i < count; i++) {
    int led = (total >= 0) ? i : 95 - i;
    frame[led / 12][led % 12] = 1;
  }
  matrix.renderBitmap(frame, 8, 12);
}
  5. Upload and open the Serial Monitor: WiFi connected. The server terminal prints connected.
  6. Press your button on pin 2. The server terminal prints received: {"button": "-2"}. The device is talking.

If it does not connect: check the Arduino joined the WiFi (Serial Monitor), the server is running, and the IP in the sketch matches the one the server printed. If the Arduino is on the WiFi but never reaches the server, the network is blocking it: switch both laptop and Arduino to a phone hotspot.

Short break.

D3. Screen to Device: the Matrix Shows the Total (10 min)

  1. Add one more effect. Every time total changes, whichever button caused it, it is sent to the Arduino:

  2. Click the on-screen buttons. The matrix lights one LED per point: a positive total fills from the top-left corner, a negative total fills backwards from the bottom-right corner. Reset clears it.
