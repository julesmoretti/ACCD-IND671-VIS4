Step 1: What is Arduino?

An Arduino is an open-source microcontroller that allows users to create interactive electronic projects. It is widely used in the prototyping world due to its versatility, ease of use, and ability to control hardware components like sensors, LEDs, motors, and more. We are using the Arduino UNO WiFi Rev 4, which comes with built-in WiFi capabilities, making it ideal for IoT projects where connectivity is key. Compared to earlier versions, this model offers a more powerful processor and enhanced connectivity options.

  • void setup(): This function runs once when the Arduino is powered on or reset. It is used to initialize settings, such as setting pin modes.
  • void loop(): This function runs continuously after setup() has finished. It contains the main logic of your program that repeats indefinitely.
void setup() {
  // Initialization code here
  pinMode(LED_BUILTIN, OUTPUT); // Set built-in LED as an output
}

void loop() {
  // Main code here
  digitalWrite(LED_BUILTIN, HIGH); // Turn the LED on
  delay(1000); // Wait for 1 second
  digitalWrite(LED_BUILTIN, LOW); // Turn the LED off
  delay(1000); // Wait for 1 second
}

This sketch blinks the LED marked L on the board. It is the LED_built_in example in the class library.

Step 2: Arduino Code Compared to JavaScript

Arduino sketches are written in C++. Most of what you learned in Weeks 2–4 carries over: semicolons, if/else, for loops, functions, comments. The differences:

JavaScript (browser) Arduino (C++)
How it runs Waits for events (clicks) and reacts setup() runs once, then loop() runs over and over, thousands of times a second
Variables let total = 0; You state the type: int total = 0; float temp = 21.5; bool isOn = false; String name = "Lumi";
Constants const max = 10; const int ledPin = 7;
Functions function add(a, b) { return a + b; } The return type comes first: int add(int a, int b) { return a + b; }. A function that returns nothing is void.
Printing console.log(total); Serial.println(total);, viewed in Tools > Serial Monitor. Needs Serial.begin(9600); in setup().
Using other code import ... from '...' #include <WiFiS3.h> at the very top of the sketch
Waiting setTimeout(...) does not block delay(1000); freezes everything for one second, including reading buttons. Use millis() when you need to do two things at once.

Libraries and #include

A library is code someone else wrote for a specific job or part: WiFi, a display, a sensor. You install it once, then load it at the top of each sketch that uses it.

  • Install: Tools > Manage Libraries, search by name, click Install. Libraries that come with the board (like WiFiS3 and Arduino_LED_Matrix for the UNO R4) are already there.
  • Load: #include <LibraryName.h> for installed libraries, #include "file.h" for a file in your own sketch folder (like arduino_secrets.h for your WiFi password).
  • If you get "No such file or directory" on an #include line, the library is not installed.

Board and port

  • Tools > Board > Arduino UNO R4 Boards > Arduino UNO R4 WiFi. If it is not listed, install Arduino UNO R4 Boards from Tools > Board > Boards Manager.
  • Tools > Port: pick the one labelled UNO R4 WiFi. If none appears, try another USB-C cable.
  • Verify (the tick) compiles your code and finds errors. Upload (the arrow) compiles and sends it to the board.
  • Mac with Apple Silicon (M1 or later): if Upload fails with "bad CPU type in executable", the board's compiler needs Rosetta 2. Open Terminal, run softwareupdate --install-rosetta --agree-to-license, then click Upload again.

Step 3: The Class Library Examples

The first circuits you build are already documented in the class library, ACCD-Fritzing-Parts. Each folder has the sketch (.ino), a Fritzing wiring diagram and a README listing the parts. Open the sketch in the Arduino IDE, wire it as the diagram shows, and upload.

Example What it does Note
LED_built_in Blinks the LED marked L on the board No wiring. The same sketch as Step 1.
LED_matrix Blinks one LED of the board's 8 × 12 matrix (third row, third column) No wiring. Uses Arduino_LED_Matrix.h, which comes with the board.
LED Blinks an LED on the breadboard Put a 1 kΩ resistor between the pin and the LED's long leg: each UNO R4 pin should supply no more than 8 mA (Week 6 reading).

Potentiometer Prints the knob's position, 0 to 1023, in the Serial Monitor Open Tools > Serial Monitor at 9600 baud after uploading.

The button shortcut: INPUT_PULLUP

The UNO R4 has a resistor built into every pin. Turn it on with pinMode(buttonPin, INPUT_PULLUP); and wire the button straight from the pin to GND, with no resistor. The logic flips: the pin reads HIGH when released and LOW when pressed. The in-class buttons are wired this way.

Step 4: WebSocket Connection Strategy

Step 4a: The Overall Strategy

In this section, we will implement a WebSocket-based communication system involving three components:

  • A React app that acts as the main user interface and communicates with the server.
  • A Node.js server that manages WebSocket connections and acts as the relay between the React app and Arduino.
  • An Arduino UNO WiFi Rev 4 which connects to the WebSocket server and exchanges data.

This architecture allows the Arduino to send sensor data and receive control commands through the Node.js server, enabling real-time interaction with the React app.

Step 4b: The Three Pieces

  • The server (server.js, run with Node on your laptop): passes every message it receives on to everyone else connected. It prints your laptop's IP address when it starts; the Arduino needs that address to find it.
  • The Arduino: joins the WiFi, connects to the server with the ArduinoHttpClient library, sends a message when a button is pressed, and acts on the messages it receives.
  • The React app: connects to the server with the react-use-websocket library, updates the screen when a message arrives, and sends a message when the user does something.

Step 4c: The Messages

A message is just a short piece of text. Both sides agree on its format in advance. In class we use two:

device to screen:   {"button": "+1"}   a physical button works the Number Adder
screen to device:   TOTAL:5            the LED matrix shows the total

For your own project, each line of your midterm "Ready for hardware" list becomes one message like these.
